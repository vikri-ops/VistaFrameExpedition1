# VistaFrame Expedition

Website landing page Open Trip / OT untuk pendakian gunung dan wisata danau.

## File
- index.html
- style.css
- script.js

## Cara menjalankan
1. Simpan ketiga file dalam satu folder.
2. Buka `index.html` di browser.
3. Website sudah responsive untuk laptop dan HP.
4. Tombol WhatsApp menggunakan nomor contoh `+62 812-3456-7890`. Ganti nomor tersebut di `index.html` dan `script.js` dengan nomor WhatsApp asli.
5. Foto pada website memakai gambar online dari Unsplash. Jika ingin website bisa berjalan tanpa internet, download foto sendiri dan ubah `src` gambar menjadi file lokal.

## Fitur
- Hero modern ala referensi
- Logo VistaFrame Expedition berbasis SVG
- Navbar responsive + menu mobile
- 6 gunung + 2 danau
- Kartu harga paket
- Galeri dokumentasi open trip
- Testimoni
- FAQ dengan jawaban langsung
- Form kontak yang diarahkan ke WhatsApp
- Animasi reveal saat scroll
- Tombol kembali ke atas
- Smooth scrolling
